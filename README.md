# Crosshair Overlay

Лёгкий оверлей-прицел для игр (CS2 и др.) под Windows. Рисует прицел по центру экрана поверх игры в маленьком прозрачном окне, которое не перехватывает мышь.

*Lightweight crosshair overlay for Windows games. Draws a crosshair in the center of the screen in a tiny transparent click-through window.*

## Возможности

- Настройка цвета (пресеты + выбор оттенка), толщины и длины рисок
- Предпросмотр 1:1 на тёмном и светлом фоне
- Вкл / выкл кнопкой в окне или горячей клавишей **F8**
- Работает из трея, крестик окна сворачивает в трей
- Не читает память игры и не внедряется в процесс — это просто прозрачное окно поверх экрана

## Использование

1. Скачайте `Crosshair.exe` из [Releases](../../releases) и запустите.
2. Переключите игру в режим **«Полноэкранный в окне»** (borderless) или «В окне» — в эксклюзивном полноэкранном режиме оверлеи не видны.
3. Настройте прицел в окне программы.

Windows SmartScreen может предупредить о неизвестном издателе (exe не подписан): «Подробнее» → «Выполнить в любом случае».

> Перед использованием на FACEIT / ESEA / турнирах проверьте их правила насчёт сторонних прицелов.

## Настройки

Хранятся в `%APPDATA%\CrosshairOverlay\crosshair.ini`. Помимо того, что есть в окне, там можно задать `gap`, `dot`, `outline`, `outlinecolor`, `offsetx` / `offsety`, `monitor` и `togglekey` (редактируйте при закрытой программе).

## Сборка

Нужна только Windows — используется компилятор C# из .NET Framework 4.x, который уже есть в системе.

```
build.bat
```

Иконка `crosshair.ico` генерируется скриптом `make_icon.ps1` (если файла нет, `build.bat` создаст его сам).
